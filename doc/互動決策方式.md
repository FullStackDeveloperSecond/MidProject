# 互動決策方式

當需要組長回答多題、批次決策或整理大量待討論事項時，優先使用互動 HTML 問題表。

## 使用時機

| 情況 | 互動方式 |
|---|---|
| 只有 1-2 個簡單問題 | 直接在對話中詢問 |
| 多題需要填答案、狀態、備註 | 建立或更新互動 HTML 問題表 |
| 需要讓組員一起看或填寫 | 使用互動 HTML 問題表 |
| 需要將答案同步回 Markdown / PDF | 由互動 HTML 匯出 JSON，再整理進文件 |

## 互動 HTML 欄位

| 欄位 | 用途 |
|---|---|
| 問題 | 要決策或待討論的題目 |
| 回答 | 組長或組員填入的決議內容 |
| 狀態 | 已決議、待處理、略過 |
| 備註 | 補充原因、限制或後續事項 |

## 判斷原則

互動 HTML 是為了提高效率，不是所有問題都要使用。

如果問題很簡單，直接問答即可。
如果問題很多、容易漏掉、需要後續寫回文件，就改用互動 HTML。
