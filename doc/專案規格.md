# 餐飲地圖系統 - 專案規格

## 專案概述

| 項目 | 內容 |
|---|---|
| 專案名稱 | 餐飲地圖系統 |
| 專案目標 | 讓使用者搜尋餐廳、查看餐廳資訊、使用地圖距離搜尋、評論與收藏餐廳 |
| 專案性質 | 期中小專案 Demo，不追求商用完整度 |
| 製作時間 | 三週正式製作時間，前置作業不包含在三週內 |
| Demo 標準 | 系統可以順跑、不報錯，五大功能都有基本資料庫串接 |
| 開發策略 | 先完成必要功能，再做想要功能 |
| Demo 資料 | 使用 Seed Data，至少 20 間餐廳 |
| 報告方式 | 誰負責功能，誰報告該功能 |

## 使用技術

| 類別 | 技術 |
|---|---|
| 後端 | ASP.NET MVC、C# |
| ORM | EF Core |
| 資料庫 | MSSQL / SQL Server |
| 前端 | HTML、CSS、JavaScript、Bootstrap |
| 地圖 | Google Maps API；備案 Leaflet + OpenStreetMap |
| 版本控制 | Git、GitHub |
| 暫不納入 MVP | jQuery、Ajax |

### 4. 地圖搜尋

| 項目 | 已定義內容 |
|---|---|
| 主方案 | Google Maps API |
| 不使用 | iframe |
| 備案 | Leaflet + OpenStreetMap |
| API Key 管理 | 由地圖實作者 Alex 申請與管理 |
| 使用者位置 | 使用者手動點選地圖位置，取得經緯度作為搜尋中心 |
| 搜尋半徑 | 有半徑輸入欄位，預設 3 公里 |
| 搜尋結果數量 | 不限制餐廳數量，沿用首頁分頁 |
| 距離計算 | 使用直線距離，並以公里顯示 |
| 結果排序 | 依距離由近到遠排序 |
| 地圖標記 | 只顯示符合首頁篩選條件的餐廳 |
| 搜尋後首頁狀態 | 清空原本首頁篩選條件，以地圖距離結果為主 |
| 無經緯度餐廳 | 不加入地圖搜尋結果 |
| Marker hover 卡片 | 顯示餐廳圖片、名稱、星數、營業時間、地址 |
| Marker 點擊 | 進入餐廳詳情頁 |

### 9. 三週製作時程

| 週次 | 目標 |
|---|---|
| Week 1 | 五大功能第一版實作，每個功能都有入口頁與至少一個資料庫讀取或新增 |
| Week 2 | 功能補完整，評論、收藏、地圖串接到餐廳詳情與首頁 |
| Week 3 | 整合、修正、UI 統一、RWD、Demo 資料、簡報與最終演練 |

### 10. Demo 主流程

1. 使用者註冊 / 登入。
2. 進入首頁瀏覽餐廳列表。
3. 使用關鍵字、標籤、地區、營業狀態或地圖搜尋餐廳。
4. 點進餐廳詳情頁，查看餐廳資訊、圖片、地圖、星等與評論。
5. 登入使用者新增評論、給星等、收藏餐廳。
6. 進入個人頁查看自己的評論與收藏。
7. 登入使用者新增或編輯餐廳資料。
